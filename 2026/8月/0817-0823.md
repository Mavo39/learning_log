## 8/18(火) 

- `uv` を使った開発についてレクチャーを受けた
- `uv add ライブラリ`
- `uv run python スクリプトファイル名`
- uv が作成する仮想環境（.venv）は、デフォルトでグローバル環境（システム標準のPython環境）のパッケージから完全に隔離された状態で動作するため、グローバル環境のライブラリは使用できない
- これまで仮想環境に `pip` しか使ったことがなかったので、新しい手段を手に入れた
- 今回の課題のように、プログラムとして作成したフォルダ自体を仮想環境化して閉じ込めるには使い勝手がいいとわかった
- ライブラリのインストールなども指定すれば自動的にしてくれるのですごく便利
