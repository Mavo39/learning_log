- Python において `__file__` は、「現在実行されている .py ファイル自身のパス」を保持する特殊変数
- `Path(__file__).resolve().parent` を使用したことで、実行する場所を変えても問題なくスクリプトを実行できた
- トランザクションを使って、既存のRedshift内のデータの一部を更新する処理するスクリプトを開発
- これまでは基本、積み上げ型で処理する都度データが積みあがっていたが、より柔軟に既存データを変更して、別システムに反映できるようにしたいことから開発した
- これによって、既存データの更新処理途中で処理が止まってもデータを失わずに済む。かつ、トランザクションを概念としてではなく、実践として体感することができたのは大きな学びだった
- `__file__` は Python のスクリプトファイル（.py）として実行される際に定義される特殊変数であるため、.ipynb では使用できない
- globモジュールの `glob()` はリストを返すが、Pathオブジェクトの `glob()` はイテレータを返す 

```python
# リスト：1,000万個の要素をすべてメモリに生成・確保する 
# -> 数百MBのメモリを即座に消費 
hoge_list = [i for i in range(10_000_000)] 

# イテレータ（ジェネレータ）：要素の生成ルールだけを保持する 
# データ数に関わらず数十バイト程度のメモリしか消費しない 
hoge_iter = (i for i in range(10_000_000)) 
```
